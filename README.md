# CECS2 — CS2 Server Manager

Бесплатный десктопный менеджер CS2 dedicated серверов на базе Tauri + Rust.

## Возможности
- 🚀 Запуск/остановка/рестарт серверов одной кнопкой
- 🎮 Управление игроками — кик
- 💬 Чат в сервер с цветами
- 📺 GOTV встроено — подключайся через консоль CS2
- 🔧 RCON консоль для любых команд
- 📊 Live статистика по localhost (открывается в браузере)
- 🗺 Быстрая смена карты
- ⚡ Автоустановка Metamod + CounterStrikeSharp - ЕЩЕ В РАЗРАБОТКЕ
- 🏆 Итог раунда и MVP в чат автоматически - ЕЩЕ В РАЗРАБОТКЕ

## Стек
Tauri 2 · Rust · SvelteKit · TypeScript

## Ответы на вопросы
Сначала вам надо указать директорию игры CS2 именно игры 
Пример
D:\SteamLibrary\steamapps\common\Counter-Strike Global Offensive
## Не работает управление
Чтоб работало управление и команды обязательно установите RCON пароль в панели при создании/редактировании сервера
## Как подключиться к серверу
команда CS2 Connect (локальный IP):(Порт)
Пример
192.168.10.199:27015 - Играть
192.168.10.199:27020 - GOTV
